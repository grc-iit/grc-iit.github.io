Research areas

Gnosis Research Center develops computing systems for data-intensive science. Its research spans memory systems architecture, parallel and distributed I/O, resource management, and agentic science and AI.

  • Memory Systems Architecture

    Memory hierarchy modeling, cache management, and compile- and run-time tools for high-performance systems.

  • Parallel and Distributed I/O

    I/O buffering, parallel file systems, and data movement across deep memory and storage hierarchies.

  • Resource Management

    Task scheduling, data placement, and fast data access for high-end computing.

  • Agentic Science and AI

    Context engineering and agent coordination for autonomous discovery: the CLIO architecture within IOWarp, memory layers for multi-agent systems, and AI-driven scientific workflows.
