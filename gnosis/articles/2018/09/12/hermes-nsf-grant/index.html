SCS Lab receives NSF framework grant for Hermes

Grants & Funding · September 12, 2018 · One min read
Gnosis Research Center

The National Science Foundation has awarded a Framework Grant (OAC-1835764) to Xian-He Sun for the Hermes project, a heterogeneous-aware multi-tiered distributed I/O buffering system designed to address the growing performance gap between computing power and storage systems.

The Hermes design​

Computing power on supercomputers has grown much faster than storage performance, a gap researchers call the "storage wall." Hermes addresses it by managing data across multiple storage tiers, from memory to disk.

The project extends the widely used HDF Library to support intelligent I/O buffering for deep memory and storage hierarchy systems, making high-performance I/O accessible to the broader scientific computing community. It is a collaborative project with The HDF Group: the award lists Gerd Heber, Ann Johnson and Elena Pourmal of The HDF Group as co-PIs.

Why it matters​

Scientific applications write and read large datasets through storage hierarchies that now include memory, node-local NVMe, burst buffers, and parallel file systems. Hermes buffers I/O across those tiers so that applications spend less time waiting for data.
