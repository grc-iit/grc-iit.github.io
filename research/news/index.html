CLIO autumn releases add Intel GPU support and a data agent

CLIO components shipped between October 8 and November 13, 2026. CLIO Core 2.3 brings its GPU runtime up on Intel GPUs, CLIO Agent 0.9.6 runs scripts against its own tools and keeps long jobs in the background, and Agent Marketplace 0.7 adds CLIO Data for HDF5, netCDF-4, ADIOS2 and Parquet. The latest versions are Agent 0.9.7, GACT TUI 0.13 and Marketplace 0.8.

Nov 122026

ChronoLog 3.3 to 3.5 add durable writes and a new dependency stack

Three releases followed 3.2 between October 15 and November 12, 2026. Version 3.3 indexes the HDF5 archive through per-ChronoGrapher manifest logs, and 3.4 adds opt-in durable writes that return only after the event is on disk in ChronoKeeper's write-ahead log. Version 3.5 moves to Spack 1.2.2, Mercury 2.4.1 and Margo 0.24.4, so all servers and clients must upgrade together.

Oct 22026

ChronoLog 3.2 keeps every chunk until it is archived

Released October 2, 2026, after 3.1.0 and 3.1.1 in September, the version has each ChronoKeeper hold a sealed chunk until ChronoGrapher confirms it is in the HDF5 archive, and replays read unarchived events directly from the keepers. Clients built against 3.1 must be rebuilt because the protocol version changed.
