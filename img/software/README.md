# Product artwork

CLIO product marks are separate brands. Do not use the Agent owl for Core,
Kit, or Coder. Canonical paths are declared in data/resources/software.yaml.

Verified against the product sites on 2026-11-14:

- clio-agent/mark.svg: https://clio.iowarp.ai/clio-mark-small.svg, copied unchanged.
- clio-coder/mark.webp: https://coder.iowarp.ai/assets/brand/clio-mark.webp, copied unchanged.
- clio-core/mark.svg: https://core.iowarp.ai/assets/brand/clio-core-mark-light.svg,
  the dark teal artwork for a light ground, copied unchanged.
- clio-core/mark-dark.svg: https://core.iowarp.ai/assets/brand/clio-core-mark.svg,
  the bright cyan artwork for a dark ground, copied unchanged.
- Kit uses /img/projects/iowarp/mark-2026.webp, copied from
  https://github.com/iowarp/iowarp.github.io/blob/main/public/images/brand/iowarp-mark-256.webp.
  Its master public/images/iowarp_logo.png is byte-identical to
  https://toolkit.iowarp.ai/img/iowarp_logo.png. The same optimized master
  supplies the IOWarp project mark.

The Kit repository and toolkit.iowarp.ai currently publish this shared IOWarp
artwork, not a separate Kit symbol. Keep that attribution explicit; do not
invent a distinct mark or use the Agent owl as a replacement.

Older assets remain available for historical content and stable image URLs.
