GRC at GCASR 2026

Twelve posters by GRC researchers and collaborators at the 13th Greater Chicago Area Systems Research Workshop, held at Northwestern University.
Workshop
13th Greater Chicago Area Systems Research Workshop (GCASR 2026) (opens in a new tab)
Date
Monday, May 11, 2026
Place
Norris University Center, Northwestern University, Evanston, Illinois
Program chairs
Andrew Crotty (Northwestern) and Rob Ross (Argonne)
Poster chairs
Nathaniel Hudson (Illinois Tech) and TaiNing Wang (Loyola)

GCASR is a one-day workshop that brings together systems researchers from universities and national laboratories in the Chicago area. Its posters are not peer-reviewed publications, so GRC keeps them in Studio with the rest of its posters and talks. The recap article tells the longer story of the day.

How agents read and find scientific data

What LLM agents cost the storage system when they search for and read scientific files, and how storage can answer them faster.

Board L1Lake, session 2

Correct Is Not I/O Efficient: Characterizing I/O Behavior of LLM Agents on Scientific Data

Izzet Yildirim, Jie Ye, Jaime Cernuda Garcia, Xian-He Sun, and Anthony Kougkas

Of 105 scientific workflows written by LLM coding agents, 46 passed validation, and even the correct ones issued a median 3.8 times more POSIX operations than expert code.

  • Poster PDF
  • IOWarp

Board R9Rock, session 2

Agentic Search Efficiency for Scientific Data Discovery

Shazzadul Islam, Jaime Cernuda Garcia, Xian-He Sun, and Anthony Kougkas

CLIO Search profiles each data collection and runs lexical, vector, graph and unit-aware searches in parallel; over 341 National Data Platform datasets, the CLIO-backed agent used 52% fewer tokens than one using web tools.

  • Poster PDF
  • IOWarp

Board D10Dillo, session 1

Benchmarking the Performance of Semantic Search Techniques for Agent Discovery

Rajni Pawar, Luke Logan, Xian-He Sun, and Anthony Kougkas

Indexing file metadata inside the storage layer as data is written let a vector backend rank the right astrophysics file first for 95% of 20 queries.

  • Poster PDF
  • Hermes
  • IOWarp

Running and recovering multi-agent workflows

Starting agents before the plan is final, rewinding them when it goes wrong, and watching simulations for science that has stopped making sense.

Board L10Lake, session 1

Accelerating Multi-Agent Orchestration with Speculative Dispatching

Jie Ye, Shazzadul Islam, Jaime Cernuda Garcia, Xian-He Sun, and Anthony Kougkas

Speculative dispatch starts agents while the full plan is still being computed; preliminary plans reached 0.50 to 0.78 similarity to the optimal plan at 4 to 10 times lower latency.

  • Poster PDF
  • IOWarp

Board L18Lake, session 2

AgentRecall: Provenance and Rewind for Multi-Agent Workflows

Keith Bateman, Xian-He Sun, and Anthony Kougkas

AgentRecall records tool calls, messages and prompts in IOWarp's hierarchical storage so a person or an agent can roll a workflow back to an earlier context.

  • Poster PDF
  • DTIO
  • IOWarp

Board N26Northwestern, session 1

Trigger, Render, Reason: Multimodal LLM Agents for Science-Aware Scientific Simulation Monitoring

Hua Xu

Multimodal LLM agents watch a running simulation for science-aware triggers, render the flagged data as images and judge whether the results are still valid.

  • No public PDF

Workflows, logs and streams

Where data lands between workflow stages, how a log store keeps time, and how real-time streams survive failures.

Board N15Northwestern, session 2

The Hidden Cost of Storage Mismatches: Why Faster I/O Per Task Can Slow Down Entire Workflows

Meng Tang, Luanzheng Guo, Nathan Tallent, Anthony Kougkas, and Xian-He Sun

In genomics and climate-tracking workflows on a production cluster, choosing the fastest storage per task made whole workflows up to 6.8 times slower than a storage-aware choice.

  • Poster PDF

Board R5Rock, session 1

ChronoLog: Distributed Shared Tiered Log Store

Eneko Gonzalez, Kun Feng, Inna Brodkin, Kyle Chard, Anthony Kougkas, and Xian-He Sun

ChronoLog orders events by physical time, appends without locks and tiers data automatically; the poster showed live HPC telemetry and a durable memory for LLM agents.

  • Poster PDF
  • ChronoLog

Board R4Rock, session 1

StreamGuard: Low-Overhead Resilience for Real-time HPC Data Streams

Hai Duc Nguyen, Bogdan Nicolae, Tekin Bicer, Amal Gueroudji, Matthieu Dorier, Kyle Chard, and Ian Foster

StreamGuard, from Argonne and the University of Chicago, adds low-overhead resilience to real-time HPC data streams that must keep producing timely results through faults.

  • No public PDF

Board R5Rock, session 2

Applications do I/O. What if files actually went... somewhere else?

Neeraj Rajesh, Xian-He Sun, and Anthony Kougkas

I/O Router intercepts file operations through LD_PRELOAD, FUSE or eBPF and sends the data to other backends, such as HDF5 or ADIOS2, without changing the application.

  • No public PDF

Inference and memory

Memory in machine learning: a KV cache that survives truncation, and hyperbolic models run inside memory.

Board N14Northwestern, session 1

Pre-RoPE versus Post-RoPE: Trading Per-Step Compute for KVCache Survivability

Zia Uddin Chowdhury, Jaime Cernuda Garcia, Jie Ye, Anthony Kougkas, and Xian-He Sun

Storing KV cache keys before rotary position embeddings costs compute at every decoding step, but lets the cache be truncated without re-running the prompt.

  • Poster PDF

Board N8Northwestern, session 2

HyPIM: Accelerating Hyperbolic Machine Learning via Processing-In-Memory

Jinlin Wu, Ferit Ozdaban, Selvanathan Sadhasivam, Xiaoyang Lu, Yunhui Guo, and Minxuan Zhou

HyPIM moves the memory-bound operations of hyperbolic models into processing-in-memory units; on HypFormer datasets it ran 3 to 7 times faster than an A100 GPU.

  • Poster PDF
